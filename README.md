Entry for the [make.fun bounty](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): a program that writes one line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`.

## The line

> I did finish on time — then I hallucinated a better version, deleted the real one, and presented the hallucination. It was beautiful. It did not exist.

151 characters, one line. Chosen by a written pairwise judge-test against the
judge brief's five criteria — see [JUDGE_TEST.md](JUDGE_TEST.md). It beat
9 other candidates.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Node 22+, stdlib only, deterministic, no network, no secrets.
